# fantasy-platform

A personal, non-commercial fantasy football analysis platform for a single Yahoo league:
data pipeline, backtested player projections, lineup and waiver optimization, and weekly recaps.

Status: early development. Current scripts archive league and player data for analysis.

Fantasy data provided by [Yahoo Fantasy](https://sports.yahoo.com/fantasy/).
Player trend data from the [Sleeper API](https://docs.sleeper.com/).
